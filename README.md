# Python Codespaces Starter

Template Python sederhana untuk dijalankan di GitHub Codespaces.

## Mulai di Codespaces

1. Upload atau salin isi folder ini ke root repository GitHub.
2. Commit file-file tersebut ke branch `main`.
3. Di repository, pilih **Code → Codespaces → Create codespace on main**.
4. Setelah Codespace terbuka, jalankan di terminal:

   ```bash
   python main.py
   ```

Output yang diharapkan:

```text
Python siap jalan di GitHub Codespaces!
```

Konfigurasi `.devcontainer/devcontainer.json` memilih image Python 3.12 untuk Codespaces.
